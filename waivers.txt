# Conformance waivers.
#
# The conformance gate is RED until Ptah covers everything Atlas expresses in the
# vendored corpus. A gap/fail/panic fails the gate unless it is waived here.
#
# Format, one per line:
#   <probe> <fixture> <stage>   <reason> (ptah#NNN)
#
# The first three space-separated tokens are the match key (probe, fixture,
# stage); everything after is the human reason and must cite the tracking issue
# or say why the divergence is intentional and permanent.
#
# A waiver only means "this gap is consciously tracked, do not fail the build on
# it yet" — NOT "this is fine forever". Keep this list as short as honesty allows.
# An empty list means: nothing is intentionally skipped, so every open gap is red.
#
# The list is empty, and the eleven migrate-runtime waivers that stood here were
# not absorbed anywhere -- their fixtures were repaired, which is the outcome a
# waiver exists to make possible rather than to replace.
#
# Ten were one cause, and this file already named the question: "whether the
# harness should connect scoped or the refusal is stricter than Atlas is
# undecided, and #289 says what measurement would settle it." The measurement
# settles it for the harness. `migrate apply` was run twice against the same
# MySQL 8.4 server on the same one-statement migration naming a scratch
# database: connected elsewhere it is refused, connected to that database it
# applies. Ptah's refusal is its documented tx-mode file contract -- it verifies
# every target table is InnoDB by reading information_schema for the connection's
# schema, and cannot make that guarantee for a database it is not connected to --
# and the diagnostic prescribes the fix it now gets: "use a connection scoped to
# that database or tx-mode none". The cross-database form was incidental
# scaffolding for an isolated scratch schema, not the behavior those cells
# measure.
#
# The eleventh was a transcription: the fixture pinned Ptah's exact sentence for
# the tx-mode all check refusal, and v0.4.0 kept every part of it while adding
# its reasoning between them. It now asserts the parts that carry the meaning.
